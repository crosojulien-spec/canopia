# Experimental component for the hackathon

Do not build this component during preparatory reconstruction.

## Approved intent

Start from interests and contextual details voluntarily expressed in the Canopia conversation. Research additional public information about the person related to those details. Use the findings to imagine more relevant personal touches or experiences, check them against hotel DNA, then submit several proposals for human selection before incorporating them into briefs.

The experiment should establish what research actually adds. Adoption into Canopia and conditions for use with real guests remain open.

Choosing creativity as the objective does not mean Julien excluded all person-focused research. He explicitly wants to test targeted research connected to interests already mentioned. Do not silently reduce the component to city or hotel research.

## Proposed data exchange

| Candidate input | Purpose |
|---|---|
| Explicitly shared interests and wishes | Justify research topics |
| Stay context | Assess relevance to this stay |
| Identification details available for the test | Avoid attributing findings to the wrong person with the same name |
| Hotel DNA version | Examine usable capabilities and constraints |
| Accessible sources and test scope | Establish what can actually be researched |

| Candidate output | Purpose |
|---|---|
| Finding, source, date and uncertainty | Enable evidence review |
| Connection to a declared interest | Exclude irrelevant information |
| Service proposal and required capabilities | Connect research to the product |
| Points to confirm | Prevent an inference from becoming an assumed fact |
| Human decision: retain, edit or discard | Control what enters the brief |

Sources and uncertainty remain available for review even when the final operational brief omits technical citations.

## Open questions

- Where exactly should the agent sit: alongside initial generation, before generation or as enrichment of an existing draft?
- Which people and sources will be used for tests? Julien mentioned public figures as a possibility without choosing a list.
- Which platforms and data are actually accessible? Do not promise access to private accounts or unavailable capabilities.
- How should additional value be measured against conversation plus DNA alone?
- How would the process be explained to a traveller in possible real use? Human approval of proposals does not itself settle information-collection conditions.

## Proposed evaluation

Compare an output using conversation plus DNA with an output using the same inputs plus research. Show what changes, what is discarded and why. Finding no useful information is a valid result. Do not invent a public presence for a fictional character or attribute information to someone whose identity is uncertain.

Julien's spoken examples explained the mechanism. Do not turn them into mandatory scenarios or build the entire component around one hobby.
