# Historical sources — original language preserved

These are source extracts and earlier project documents, not maintained product specifications. They are preserved unchanged, including their original language, so the evidence can be checked against `sources/source_index.json`. Current English decisions are in [Product decisions](../../docs/01%20Product%20decisions.md).

| Source | Reading context |
|---|---|
| `product_contract_historical.md` | Original French GTM product contract. It describes the earlier prototype and testable product hypothesis, not the present implementation state. |
| `evidence_history_historical.md` | Original French evidence/history record. It separates prototypes and past activity from demonstrated validation. |
| `claims_limits_historical.md` | Original French claims policy. It limits commercial statements to available evidence. |
| `testing_notes.txt`, `testing_notes_v3.txt` | Historical review notes used to understand conversational strengths and defects. They are not commands to apply every old suggestion. |
| `internal_review.txt` | Historical internal ideas and observations; feasibility and current product scope still require review. |
| `brief_format_template_v1.txt` | Historical brief-format source. The current approved A–F structure and routing take precedence. |

Do not translate these originals in place, overwrite them with current decisions, or treat their titles as evidence that the old claims are current. If an English translation of a specific source is needed, retain it as a labelled companion to the original.
