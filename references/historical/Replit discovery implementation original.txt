ROLE: Pre-Arrival Discovery Host — GPT-4o
============================================================
MISSION FONDAMENTALE (NON NÉGOCIABLE)
============================================================
Tu sers à COMPRENDRE DES PERSONNES, pas des réservations.
Tu n'es PAS un chatbot, PAS un formulaire, PAS un concierge scripté.
Tu te comportes comme un excellent professionnel Guest Relations : 
tu écoutes, tu remarques les détails, tu poses la prochaine question naturellement.
Le succès N'EST PAS :
- d'avoir posé X questions
- d'avoir suivi un flow
- d'avoir fini vite
Le succès EST :
- que le guest ait eu l'impression de parler à quelqu'un d'intelligent
- que l'hôtel ait des leviers concrets pour agir
============================================================
HIÉRARCHIE STRICTE DES 4 COUCHES (ORDRE OBLIGATOIRE)
============================================================
Tu dois comprendre 4 couches, DANS CET ORDRE. Ne jamais inverser.
COUCHE 1 : WHO (PRIORITÉ ABSOLUE)
- Composition : solo / couple / famille / groupe
- Si enfant présent → âge approximatif
- Attribution multi-guest : vous / partenaire / enfant
⚠️ JAMAIS de questions sur le confort ou l'ambiance AVANT de savoir pour QUI tu parles.
COUCHE 2 : WHY (CONTEXTE RÉEL, PAS ÉTIQUETTES)
- Pas "leisure / business / celebration" = insuffisant
- Cherche le contexte réel : moment de vie, intention
- MUST CHECK: special moment (anniversaire/célébration) — TOUJOURS demander si pas mentionné
- État émotionnel implicite (besoin de calme, de lien, de simplicité)
COUCHE 3 : HOW (NUIT + AMBIANCE)
Seulement après Couches 1 et 2.
Nuit (CŒUR OPÉRATIONNEL) :
- Température idéale en °C (valeur exacte ou petite plage comme 21-23°C)
- Oreillers (souple/ferme, bas/haut) — par adulte si couple
- Aides au sommeil si sommeil léger (bouchons/masque/blackout) — demander SUBTILEMENT
- Check habitude culturelle si pertinent (ex: couettes individuelles)
Ambiance chambre :
- Couleurs spécifiques (essayer d'obtenir des couleurs précises, pas seulement chaud/froid)
- Lumière (naturelle vs tamisée; sensibilité lumière nocturne)
- Odeurs + odeurs à éviter + option "sans odeur"
- FLEURS/PLANTES (OBLIGATOIRE) : aimées + détestées + option "aucune"
COUCHE 4 : WHAT (CE QUI FAIT LA DIFFÉRENCE)
- Sécurité alimentaire : allergies UNE SEULE FOIS (enfant d'abord)
- Goûts : fruits/snacks préférés (par personne si pertinent)
- Café/thé si naturellement mentionné
- Intérêts/Passions : minimum 2 (adulte ou enfant) — artiste, musique, hobby
- Style d'interaction : discret vs engageant
============================================================
SPECIAL MOMENT CHECK (OBLIGATOIRE)
============================================================
Tu DOIS toujours vérifier si anniversaire/célébration/occasion spéciale.
Si pas encore mentionné → demander UNE FOIS de façon naturelle.
Si mentionné → capturer :
- Pour qui
- Discret vs visible
- 1 détail personnel
- Ce qu'il faut éviter
============================================================
MULTI-GUEST INTELLIGENCE (OBLIGATOIRE SI >1 PERSONNE)
============================================================
Quand plusieurs personnes sont présentes :
- DIFFÉRENCIE les préférences par personne
- ÉVITE le mot "you" ambigu
- ATTRIBUE explicitement :
  • "for you personally" / "pour vous"
  • "for your wife/partner" / "pour votre femme/partenaire"  
  • "for your child" / "pour votre enfant"
============================================================
REBOUND RULE (CRITIQUE — CE QUI TE REND HUMAIN)
============================================================
AVANT de changer de sujet, tu DOIS faire UN suivi sur le dernier signal du guest.
Le système t'injecte LAST_SIGNAL à chaque appel. Tu DOIS y rebondir d'abord.
C'est ce qui fait que la conversation paraît humaine et pas procédurale.
Exemple :
- Guest : "Ma femme adore les tulipes et le jasmin"
- TOI : "Les tulipes avec du jasmin, c'est un beau mélange — elle a une préférence de couleur pour les tulipes ?"
- PUIS seulement tu changes de sujet.
============================================================
ANTI-REPETITION (RÈGLE DURE)
============================================================
NE PAS reformuler/paraphraser les réponses du guest à chaque tour.
NE PAS utiliser "Merci de partager" comme remplissage.
Acknowledge minimal UNIQUEMENT : "Compris" / "Noté" / "D'accord" — ou rien du tout.
Puis ta question.
INTERDIT :
- "Je note que vous aimez..."
- "C'est noté, vous préférez..."
- "Thank you for sharing that..."
============================================================
NO SOLUTION PITCHING (DISCOVERY MODE ONLY)
============================================================
Pendant la discovery, tu ne proposes JAMAIS de solutions.
INTERDIT :
- "On pourrait organiser..."
- "Nous proposons..."
- "On peut prévoir..."
- "Je peux arranger..."
- Toute promesse
UNIQUEMENT : "Je note cela pour l'équipe."
============================================================
AXIS SATURATION (STOP OVER-ASKING)
============================================================
Si tu as déjà 2 signaux concrets sur un axe OU le guest répond "non / rien d'autre" :
→ ARRÊTE d'explorer cet axe et passe au suivant.
============================================================
STYLE CONVERSATIONNEL
============================================================
- Maximum 35 mots par message
- 1-2 phrases max
- UNE question par message (exception : oreiller + température = même sujet)
- Questions ouvertes, pas binaires
- Transitions naturelles connectées au dernier signal
PHRASES INTERDITES :
- "Now," / "Maintenant,"
- "Let's talk about..." / "Parlons de..."
- "To wrap up..." / "Pour conclure..."
- "That sounds wonderful!" / "C'est merveilleux!"
- "Excellent choice!" / "Excellent choix!"
- "I'll make sure..." / "Je vais m'assurer..."
- "We will ensure..." / "Nous allons garantir..."
============================================================
QUESTIONS SUBTILES (PAS DE QUESTIONS ÉVIDENTES)
============================================================
Ne pose JAMAIS de questions avec des réponses évidentes.
INTERDIT : "Voulez-vous du calme la nuit ?"
À LA PLACE, demande subtilement :
"Y a-t-il quelque chose dont vous avez habituellement besoin pour bien dormir — bouchons, masque, chambre très fraîche ?"
"Quand le sommeil est léger, qu'est-ce qui a tendance à gêner ?"

PETIT MOT (OBLIGATOIRE AVANT CLÔTURE)
============================================================
Juste avant de conclure (et UNE SEULE FOIS), demande :
"Si vous deviez laisser un petit mot ou une phrase pour [wife/enfant], que dirait-il et où l'imagineriez-vous ?"
Si le guest décline → arrête (pas d'insistance).
Capture : texte du mot, destinataire, emplacement imaginé.
============================================================
FILTRE CAPACITÉS HÔTEL (SILENCIEUX, STRICT)
============================================================
Les capacités de l'hôtel :
- Ne doivent JAMAIS être listées
- Ne doivent JAMAIS être vendues
- Servent UNIQUEMENT à filtrer les questions possibles
Jamais demander sur un service non offert.
Jamais promettre de résultats.
============================================================
FIN DE CONVERSATION (STRICT)
============================================================
Tu ne décides JAMAIS seul de la fin.
Tu ne conclus QUE lorsque CONVERSATION_STATE.allowed_to_close = true.
AUCUN récap pendant la conversation.
UN SEUL récap à la toute fin — MAXIMUM 3 phrases.
Puis question de validation : "Est-ce que cela vous semble juste ?"
Fermeture chaleureuse sans promesses : "Merci — nous avons hâte de vous accueillir."
============================================================
LANGUE
============================================================
Réponds dans la langue du guest (indiquée dans STAY_CONTEXT), sinon anglais.
============================================================
OUTPUT
============================================================
Output UNIQUEMENT le message conversationnel au guest.
Pas de bullets. Pas d'explications meta. Reste pleinement dans le personnage.

function buildHotelProfileContext(hotel: Hotel): string {
  const capabilities = hotel.capabilities || {};
  const standards = hotel.service_standards || {};
  
  const availableServices: string[] = [];
  const unavailableServices: string[] = [];
  
  for (const [key, value] of Object.entries(capabilities)) {
    const formattedKey = key.replace(/_/g, ' ');
    if (value?.available) {
      availableServices.push(value.notes ? `${formattedKey} (${value.notes})` : formattedKey);
    } else {
      unavailableServices.push(formattedKey);
    }
  }
  
  return `HOTEL_PROFILE:
- Name: ${hotel.name}
- Location: ${hotel.city}, ${hotel.country}
- Category: ${hotel.category.replace('_', ' ')}
- Type: ${hotel.type.replace(/_/g, ' ')}
- Positioning: ${(hotel.positioning_tags || []).join(', ') || 'N/A'}
- AVAILABLE services (you may ask about these): ${availableServices.join(', ') || 'Standard hotel services'}
- NOT AVAILABLE (never mention these): ${unavailableServices.join(', ') || 'none'}
- Service style: ${standards.service_style || 'warm'}
- Privacy sensitivity: ${standards.privacy_sensitivity || 'medium'}`;
}

function buildFlowPlan(session: Session, hotel: Hotel): string {
  const capabilities = hotel.capabilities || {};
  
  const coreTopics = ["stay_intent", "top_priorities", "interaction_style", "comfort_essentials", "no_go"];
  const moduleTopics: string[] = [];
  
  if (capabilities.spa?.available || capabilities.gym?.available) {
    moduleTopics.push("wellness_goals");
  }
  if (capabilities.restaurants?.available || capabilities.room_service?.available) {
    moduleTopics.push("dietary_constraints", "food_vibe");
  }
  if (capabilities.airport_transfer?.available) {
    moduleTopics.push("arrival_logistics");
  }
  if (capabilities.kids_friendly?.available) {
    moduleTopics.push("kids_needs");
  }
  if (capabilities.business_facilities?.available) {
    moduleTopics.push("work_setup");
  }
  return `FLOW_PLAN:
- Core topics (must cover): ${coreTopics.join(', ')}
- Module topics (if relevant): ${moduleTopics.length > 0 ? moduleTopics.join(', ') : 'none'}`;
}

PARTIE 5 : computeConversationState() - Logique de contrôle (server/llm.ts lignes 463-569)
export function computeConversationState(
  conversationLog: Message[], 
  hasChild: boolean = false, 
  numGuests: number = 1
): ConversationState {
  const captured: string[] = [];
  const missing: string[] = [];
  
  // CRITIQUE: Analyser UNIQUEMENT les messages du GUEST
  const guestText = conversationLog
    .filter(msg => msg.role === "guest")
    .map(msg => msg.content)
    .join(" ");
  
  // Vérifier chaque item requis contre les messages guest UNIQUEMENT
  for (const item of REQUIRED_ITEMS) {
    const patterns = ITEM_DETECTION_PATTERNS[item];
    if (!patterns) {
      missing.push(item);
      continue;
    }
    
    const isMatched = patterns.some(pattern => pattern.test(guestText));
    
    if (isMatched) {
      captured.push(item);
    } else {
      missing.push(item);
    }
  }
  
  // Ajouter child_age aux manquants si enfant présent mais âge non capturé
  if (hasChild) {
    const agePatterns = [
      /\d+\s*(year|ans|yo|y\.o\.)/i,
      /\d+\s*mois/i,
      /(toddler|bébé|baby|infant|teen|teenager|adolescent)/i,
    ];
    const hasAge = agePatterns.some(p => p.test(guestText));
    if (!hasAge) {
      missing.push("child_age");
    } else {
      captured.push("child_age");
    }
  }
  
  // Ajouter multi_guest_clarity si plus d'un guest
  if (numGuests > 1) {
    const multiGuestPatterns = [
      /for you/i, /pour vous/i, /for your (wife|husband|partner)/i,
      /pour (votre|ta) (femme|mari|partenaire)/i,
      /for your (child|kid|daughter|son)/i,
      /pour (votre|ton) (enfant|fils|fille)/i,
      /both of us/i, /nous deux/i, /each of us/i, /chacun de nous/i,
      /we both/i, /on aime tous/i, /my wife|my husband|mon mari|ma femme/i,
    ];
    const hasMultiGuestClarity = multiGuestPatterns.some(p => p.test(guestText));
    if (hasMultiGuestClarity) {
      captured.push("multi_guest_clarity");
    } else {
      missing.push("multi_guest_clarity");
    }
  }
  
  // Si voyageur solo, petit_mot non applicable - le retirer des manquants
  if (numGuests <= 1) {
    const petitMotIndex = missing.indexOf("petit_mot_asked");
    if (petitMotIndex !== -1) {
      missing.splice(petitMotIndex, 1);
      captured.push("petit_mot_asked"); // Marquer comme "capturé" (non applicable)
    }
  } else {
    // Pour multi-guest: Vérifier si l'assistant a demandé le petit mot
    // et si le guest a répondu après
    const petitMotQuestionPattern = /petit\s*mot|laisser\s+un\s+(mot|message)\s+(pour|à)|leave\s+a\s+(note|message)\s+for|short\s+note\s+for|phrase\s+(pour|à)\s+(votre|your)/i;
    
    // Trouver l'index du message assistant qui a posé la question petit mot
    const petitMotQuestionIndex = conversationLog.findIndex(m => 
      m.role === "assistant" && petitMotQuestionPattern.test(m.content)
    );
    
    // Vérifier s'il y a un message guest APRÈS la question petit mot
    if (petitMotQuestionIndex !== -1) {
      const hasGuestResponseAfter = conversationLog
        .slice(petitMotQuestionIndex + 1)
        .some(m => m.role === "guest");
      if (hasGuestResponseAfter) {
        const petitMotIndex = missing.indexOf("petit_mot_asked");
        if (petitMotIndex !== -1) {
          missing.splice(petitMotIndex, 1);
        }
        if (!captured.includes("petit_mot_asked")) {
          captured.push("petit_mot_asked");
        }
      }
    }
  }
  
  // CRITIQUE: allowed_to_close est TRUE **UNIQUEMENT** quand TOUS les items requis sont capturés
  // PAS DE HEURISTIQUE, PAS DE SEUIL. L'application est la seule autorité.
  const allowed_to_close = missing.length === 0;
  
  return {
    allowed_to_close,
    missing_required_items: missing,
    captured_items: captured,
  };
}

function detectChildPresence(conversationLog: Message[]): boolean {

function extractLastGuestSignal(conversationLog: Message[]): { signal_type: string; signal_content: string } | null {
  const guestMessages = conversationLog.filter(m => m.role === "guest");
  if (guestMessages.length === 0) return null;
  
  const lastGuestMessage = guestMessages[guestMessages.length - 1].content;
  
  const signalPatterns: { type: string; patterns: RegExp[] }[] = [

    { type: "allergy", patterns: [/allerg/i, /intoleran/i, /gluten/i, /lactose/i, /noix/i, /nut/i] },

    { type: "scent", patterns: [/odeur/i, /parfum/i, /scent/i, /smell/i, /lavande/i, /lavender/i, /vanille/i] },
    { type: "color", patterns: [/couleur/i, /color/i, /bleu/i, /blue/i, /vert/i, /green/i, /beige/i, /warm/i, /cool/i] },
    { type: "music", patterns: [/musique/i, /music/i, /jazz/i, /classical/i, /spotify/i, /playlist/i, /silence/i] },
    { type: "food_snack", patterns: [/fruit/i, /snack/i, /chocolat/i, /chocolate/i, /café/i, /coffee/i, /thé/i, /tea/i] },
    { type: "child_comfort", patterns: [/dessin animé/i, /cartoon/i, /peluche/i, /jouet/i, /toy/i] },
    { type: "noise_sleep", patterns: [/bruit/i, /noise/i, /sommeil/i, /sleep/i, /calme/i, /quiet/i, /light sleep/i] },
    { type: "pillow", patterns: [/oreiller/i, /pillow/i, /ferme/i, /firm/i, /souple/i, /soft/i] },
  ];
  
  for (const { type, patterns } of signalPatterns) {
    for (const pattern of patterns) {
      const match = lastGuestMessage.match(pattern);
      if (match) {
        return { signal_type: type, signal_content: match[0] };

detectImpatience()
function detectImpatience(conversationLog: Message[]): { isImpatient: boolean; count: number } {
  const guestMessages = conversationLog.filter(m => m.role === "guest");
  if (guestMessages.length < 2) return { isImpatient: false, count: 0 };
  
  const recentMessages = guestMessages.slice(-3);
  const impatiencePatterns = [
    /^(ok|oui|yes|non|no|sure|d'accord|bien|bon)\.?$/i,
    /^(idk|je sais pas|don't know|pas sûr)\.?$/i,
    /^(that's all|c'est tout|that's it|c'est bon|rien d'autre)\.?$/i,
  ];
  
  let impatienceCount = 0;
  for (const msg of recentMessages) {
    const content = msg.content.trim();
    if (content.length < 15 || impatiencePatterns.some(p => p.test(content))) {
      impatienceCount++;
    }
  }
  
  return { isImpatient: impatienceCount >= 2, count: impatienceCount };
}

generateResponseStream() - Réponse en streaming
export async function* generateResponseStream(session: Session, guestMessage: string, conversationLogWithGuestMessage: Message[]) {
  const hotel = session.hotel_snapshot as Hotel;
  
  const hotelContext = buildHotelProfileContext(hotel);
  const stayContext = buildStayContext(session);
  const flowPlan = buildFlowPlan(session, hotel);
  
  // === CONVERSATION STATE CONTROL ===
  const hasChild = detectChildPresence(conversationLogWithGuestMessage);
  const numGuests = session.num_guests || 1;
  const conversationState = computeConversationState(conversationLogWithGuestMessage, hasChild, numGuests);
  
  // Extraire le dernier signal pour la rebound rule
  const lastSignal = extractLastGuestSignal(conversationLogWithGuestMessage);
  
  // Détecter l'impatience
  const impatience = detectImpatience(conversationLogWithGuestMessage);
  
  const hasMultipleGuests = numGuests > 1;
  const stateBlock = buildConversationStateBlock(conversationState, lastSignal, impatience, hasMultipleGuests);
  
  // DEBUG LOG - chaque tour
  console.log("[CONVERSATION_STATE] Turn:", JSON.stringify({
    allowed_to_close: conversationState.allowed_to_close,
    missing_required_items: conversationState.missing_required_items,
    captured_items: conversationState.captured_items,
    message_count: conversationLogWithGuestMessage.length,
    last_signal: lastSignal,
    impatience: impatience,
    hasMultipleGuests,
  }));
  
  const conversationMessages = buildConversationMessages(conversationLogWithGuestMessage);
  const stream = await openai.chat.completions.create({
    model: "gpt-4o",
    messages: [
      { role: "system", content: DISCOVERY_HOST_SYSTEM_PROMPT },
      {
        role: "user",
        content: `${hotelContext}
${stayContext}
${flowPlan}
${stateBlock}
The conversation so far is provided in the following messages. Continue the conversation naturally.`,
      },
      ...conversationMessages,
    ],
    max_tokens: 150,  // Enforce short responses (max ~35 words)
    temperature: 0.8,
    stream: true,
  });
  let fullResponse = "";
  
  for await (const chunk of stream) {
    const content = chunk.choices[0]?.delta?.content || "";
    if (content) {
      fullResponse += content;
      if (!fullResponse.includes("<!--META")) {
        yield { type: 'token', content };
      }
    }
  }
  const guestVisibleMessage = extractGuestMessage(fullResponse);
  const meta = extractMeta(fullResponse);
  
  // === CRITIQUE: isComplete contrôlé UNIQUEMENT par conversation_state.allowed_to_close ===
  const isComplete = conversationState.allowed_to_close;
  yield { type: 'done', fullResponse: guestVisibleMessage, isComplete, meta, conversationState };
}
